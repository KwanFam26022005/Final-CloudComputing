Bài viết 2: Tìm hiểu Microservices, API Gateway & Cân bằng tải Nginx

API Gateway đóng vai trò là điểm truy cập duy nhất (Single Entry Point) cho toàn bộ hệ thống, giúp ẩn cấu trúc mạng nội bộ và định tuyến yêu cầu theo đường dẫn (Path-based Routing).

Khi lưu lượng tăng cao, thuật toán Round Robin phân phối tuần tự các request giữa web-frontend-server1 và web-frontend-server2 để tăng tính sẵn sàng.
