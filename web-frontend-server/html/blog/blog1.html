Bài viết 1: Tổng quan Kiến trúc Điện toán Đám mây & Container hóa

Điện toán đám mây (Cloud Computing) kết hợp với công nghệ Docker Container giúp chuẩn hóa môi trường triển khai từ máy cá nhân (Local) lên hạ tầng đám mây công cộng như AWS EC2.

Trong hệ thống MyMiniCloud, mỗi máy chủ đảm nhận một vai trò độc lập và giao tiếp qua mạng ảo nội bộ cloud-net.
